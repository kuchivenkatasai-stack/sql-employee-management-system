# SQL Employee Management System

## About the Project

This project is a SQL-based Employee Management System developed using MySQL. The main objective of the project is to demonstrate how a relational database can be designed and used to manage employee-related information efficiently.

The database stores details such as employees, departments, qualifications, salaries, and other related information while maintaining proper relationships between tables using primary and foreign keys.

This project helped me strengthen my understanding of database design, SQL queries, joins, constraints, and data retrieval techniques through practical implementation.

1. Install MySQL Server and MySQL Workbench.
2. Open the `sql_final_project.sql` file.
3. Execute the SQL script.
4. The database and tables will be created automatically.
5. Run the sample queries to explore the database.
